Google Drive Connection

This single-file app uses Google Identity Services and the Google Drive API. It does not ask for or store your Google password.

One-time setup: In Google Cloud Console, create/select a project, enable Google Drive API, configure the OAuth consent screen, create an OAuth Client ID of type “Web application”, and add the website origin to Authorized JavaScript origins. Paste the Client ID below.

Recommended scope: https://www.googleapis.com/auth/drive.file. The app can create and manage files it creates or that you explicitly open with it. Use a trusted computer and keep regular backups.
